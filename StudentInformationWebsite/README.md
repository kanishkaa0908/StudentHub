# StudentHub — Student Information System

A responsive student-record management website built with HTML, CSS, and JavaScript.

## Features
- Add student records
- Search by name, register number, department, or email
- Delete student records
- Dashboard statistics
- Responsive mobile layout
- Saves records in browser local storage

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Note
This is a front-end learning project. Data is stored in the current browser only; it does not use a server or shared database.
